# Employee Dashboard | Microsoft Excel

## 📌 Project Overview

This project is an interactive **Employee Dashboard** created using Microsoft Excel to analyze workforce data and present key HR insights in a clear and visually engaging way. The dashboard enables users to explore employee information through dynamic charts, KPIs, and interactive filters, supporting better business and HR decision-making.

## 🎯 Objectives

* Analyze employee demographics and workforce distribution.
* Monitor employee attrition and active workforce.
* Explore trends by city, education level, experience, payment tier, and joining year.
* Present HR metrics through an interactive dashboard.

## 🛠 Tools & Skills

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Data Visualization
* Dashboard Design
* KPI Reporting

## 📊 Dashboard Highlights

* Total Employees
* Active Employees
* Employees Left
* Employee Attrition Rate
* Average Employee Age
* Employee Distribution by Gender
* Employee Distribution by City
* Employee Distribution by Education
* Employee Distribution by Experience
* Employee Distribution by Payment Tier
* Employee Distribution by Joining Year

This project demonstrates my ability to transform raw HR data into meaningful insights by building an interactive and user-friendly dashboard using Microsoft Excel.
